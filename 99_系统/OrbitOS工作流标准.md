# OrbitOS 工作流标准

## 核心闭环

捕获 -> 规划 -> 执行 -> 回写 -> 复盘 -> 归档

## 执行原则

- 收件箱只做入口，不做长期仓库
- 日记承接当天执行，项目承接连续推进
- 模板负责结构，技能负责填充
- 先有标准，再有模板，再有技能

## 推荐路径

1. 外部输入先进入 `00_收件箱`
2. 需要连续推进的内容用 `/kickoff` 转项目
3. 每天通过 `/start-my-day` 选择一个最小执行步
4. 在 `10_日记` 记录真实执行
5. 用 `/update-project` 回写项目
6. 阶段结束时用 `/project-review`
7. 月初用 `/monthly-review`
