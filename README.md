# Jarvis for Obsidian

![](99_系统/附件/Pasted%20image%2020260324160743.png)

一个面向通用用户的 Jarvis 管理系统开源版：以 Obsidian 作为本地记忆中枢，以 Claude Code / Codex / Gemini 作为行动与编排入口，把收件箱、日记、项目、研究、知识和复盘串成一个可持续运转的闭环。

本仓库是从私有 OrbitOS 实践中脱敏整理出的通用版本。目标不是展示一个“很会记笔记”的仓库，而是提供一套可以直接开始使用、也可以继续演化的个人管理系统骨架。

开箱即用意味着三件事：

- 克隆后目录骨架、模板、MOC 入口已经齐全
- 主要代理入口共享同一套系统规则与技能定义
- 用户第一次打开仓库时，看到的示例内容本身就符合当前规则

## 这套系统解决什么问题

- 所有输入先有落点，不必靠脑子记住
- 每天只关注今天最值得推进的一小步
- 项目能和每日日记联动，不容易推进断档
- 月度总结、项目复盘和归档有固定出口，仓库能长期保持整洁

## 核心工作流

1. 想法、网页、零散事项先进入 `00_收件箱`
2. 需要持续推进的内容用 `/kickoff` 转成 `20_项目`
3. 每天通过 `/start-my-day` 生成当日最小执行安排
4. 执行过程记录在 `10_日记`
5. 通过 `/update-project` 把真实执行结果回写项目
6. 阶段结束时用 `/project-review` 做复盘
7. 月初用 `/monthly-review` 做月总结并归档上月日记

## 最小上手

如果只想记住最关键的入口，先用这 6 个：

- `/init`：第一次启动系统，建立用户上下文并完成首次引导
- `/start-my-day`：开始今天
- `/kickoff`：把想法转成项目
- `/ask`：快速问问题
- `/update-project`：把日记回写项目
- `/monthly-review`：做月总结并归档

如果需要资讯入口，再加 1 个：

- `/daily-digest`：统一查看 AI 新闻、AI 产品和 GitHub 热点

## 目录职责

### `00_收件箱`

- 接住所有临时输入
- 适合放想法、网页剪藏、零散 todo、待处理事项
- 原则是尽快分流，不长期堆放

### `10_日记`

- 承接每天的执行记录和反馈
- 是项目回写、月总结和复盘的重要证据来源

### `15_领域`

- 管长期责任、背景和持续关注方向
- 为项目提供上下文，不直接承担短期执行

### `20_项目`

- 管需要连续推进的事项
- 每个项目统一使用“主文件 + 资料 + 复盘”三文件结构

### `30_研究`

- 管需要系统搜集、整理、分析的主题

### `40_知识库`

- 管原子概念和长期可复用知识

### `50_资源`

- 管值得保留、以后还会反复使用的外部资料

### `90_计划`

- 管阶段性路线、方案和系统级计划

### `99_系统`

- 管模板、规则、提示词和系统标准

## 关键技能

### 工作流

- `/init`：首次启动向导
- `/start-my-day`：晨间规划
- `/kickoff`：收件箱条目转项目
- `/update-project`：按某一天日记回写项目
- `/project-review`：阶段或项目复盘
- `/monthly-review`：月度总结与日记归档
- `/research`：深度研究并产出研究笔记

- `/ai-products`：AI 产品动态
- `/github-trending`：GitHub 热点项目

- `obsidian-markdown`

## 开始使用

1. 安装 [Obsidian](https://obsidian.md/) 和 [Claude Code](https://claude.ai/code)
2. 克隆仓库

```bash
git clone https://github.com/Muliminty/jarvis-obsidian-claude.git
cd jarvis-obsidian-claude
```

3. 用 Obsidian 打开当前目录
4. 在您偏好的代理工具中打开同一目录：
   - Claude Code
   - Codex
   - Gemini
5. 第一次使用建议先执行 `/init`
6. 之后再从 `/start-my-day` 或 `/kickoff` 开始

如果需要更强的搜索能力，可按需配置 `.env.exa.example`。

## `/init` 会做什么

`/init` 不是一份静态教程，而是一轮真实的首次协作。

执行后，Jarvis 会：

1. 用几轮轻量对话了解你的称呼、关注方向、当前阶段和建议偏好
2. 把这些内容整理进 `99_系统/用户画像与上下文.md`
3. 根据你的状态，直接带你进入第一次真实动作：
   - 开始今天：`/start-my-day`
   - 把想法变成项目：`/kickoff`

它的目标不是让你先学会所有命令，而是让你在第一次使用时就感受到“系统开始理解我了”。

## 开源版定位

这个仓库优先提供“通用骨架”而不是某个具体用户的私人上下文，因此做了几类收敛：

- 保留稳定结构，不公开私人数据
- 保留技能入口，不绑定个人节奏细节
- 保留命名与模板规则，不暴露私有知识库路径

如果您打算基于它继续深度定制，建议优先修改：

- `99_系统/OrbitOS-统一AI提示词.md`
- `99_系统/用户画像与上下文.md`
- `99_系统/文件命名规范.md`
- `99_系统/模板/`
- `.agents/skills/`
